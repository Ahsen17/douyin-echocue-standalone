# M5-05 实现确定性 PromptAssembler

## 状态
已完成（2026-08-22，SubAgent 自检通过）

## 实现说明

### 包含范围
- `PromptAssembler.ts`：
  - `renderPrompt(input): RenderedPrompt`——纯函数、确定性，相同输入逐字节同 prompt（无时间/随机/Map 遍历序依赖，user payload 键序固定）
  - `estimateTokens(s)`——启发式 token 估算（CJK 码点≈1 token，其余≈1/4），仅用于硬预算判定，保持纯函数
  - 冻结常量：`PROMPT_TEMPLATE_VERSION_V1` / `PROMPT_ASSEMBLER_VERSION_V1` = `'v1'`、`USER_CONTRACT_ID_V1 = 'echocue.reply_generation.v1'`、`DEFAULT_CONTEXT_BUDGET_TOKENS = 4096`（POC 校准占位）
  - `toReferenceCase`：把 `RetrievalHitV1` 映射为参考案例，白名单取字段，丢弃 case_id/pointId/rawScore/retrievalConfidence/quality_score/enabled/is_bad_case/tokenizer_version/source_trace_id/时间戳
- `types.ts`：`PromptInput` / `ReferenceCase` / `TruncationLog` / `RenderedPrompt` 等快照与 I/O 类型；`ReferenceCase.source` 用契约 `SourceCollectionV1`（不手写枚举）
- `index.ts`：桶导出
- 测试：`tests/unit/prompt/prompt-assembler.test.ts`（13 用例：正常渲染 / golden+pre_set 映射 / 可选字段省略 / 标识符不泄漏 / 确定性 / 截断 4 用例含空输入 / 注入隔离 / estimateTokens）

### 消息布局（LLM §3.2）
- 1 条固定 system（`SYSTEM_MESSAGE_V1` 逐字冻结，含弯引号「“数据”」，无变量、无历史、无 CoT）+ 1 条 user（JSON 序列化）
- user JSON 固定键序：`contract` / `target_comment` / `persona{persona_id,persona_version,content}` / `team_boundaries{version,policy_text,keywords}` / `reference_cases` / `output_contract`
- pre_set 提供 类型/描述/参考表达（description/reference_reply/reference_cues），golden_set 提供 认可回复与提词（reply/cues）；可选字段缺省时键整体省略

### 注入隔离
- 所有动态内容（弹幕/人设/安全政策/案例）经单次 `JSON.stringify` 作为字符串值进入 user，无字符串拼接，结构性转义
- 注入不进入 system 指令区；不引入新顶层键；rendered prompt 无 API key / Authorization / rawScore / 置信度 / 阈值 / pointId / caseId / content_hmac

### 确定性截断（LLM §3.1/§3.3）
- 固定部分（目标弹幕/人设/安全边界）永不截断，即使 base 自身超预算也完整渲染
- 按 rerank 顺序贪心前缀纳入案例，超出 `maxContextBudget` 即从尾部丢弃；`truncationLog.excludedCases` 仅随返回值供审计，不进入 user
- 预算仅约束序列化后的 user 消息（system 不计）；若 POC 校准的是整段 prompt 上限，调用方须传 `cap - estimateTokens(system)`

### 不包含范围
- 输出校验器（M5-06）、SuggestionAttempt 编排（M5-07）、时钟/deadline/abort（M5-08）、审计快照落库（M5-09）
- 预算/TopK/输出措辞的 POC 校准值（LLM §3.3 留待受控配置；当前 `DEFAULT_CONTEXT_BUDGET_TOKENS` 为占位）

### 关键决策
- 单源枚举：`ReferenceCase.source` 直接引用 `@echocue/contracts` 的 `SourceCollectionV1`，不复制字面量并集（CLAUDE.md 单源原则）
- 截断为贪心前缀：包含集恒为 rerank 前缀、丢弃集恒为连续尾部，保证"最长可容纳前缀"语义且确定性
- 预算口径（user-only）与 POC 占位在代码注释显式标注，供 M5-07 编排器与 POC 记录对齐
