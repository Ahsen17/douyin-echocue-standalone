## 实现说明

### 包含范围
- `src/main/suggestion/SuggestionAttemptOrchestrator.ts`：实时编排器（ARCH §4/§4.1、ATLAS §4/§7.2/§8.2）——
  - 单时刻一个 attempt；DISPLAYING 守卫：新弹幕 `RECEIVED→NORMALIZED→DISCARDED(DISPLAY_WINDOW_ACTIVE)`，不检索/不生成/不入队
  - 会话去重（source_message_id，有界 Set≤100k）+ 输入安全（冻结 CompiledSafetyRuleV1）+ 成员路由（PersonaRouter）
  - 并行检索（SuggestionRetriever）→ `evaluateRetrieval` 校准/rerank/语义初筛 → 直出决策
  - golden 直出优先：`evaluateDirectPush` eligible → 共用输出校验通过 → `RETRIEVING→DIRECT_READY→DISPLAY_READY`（不调 LLM）；校验失败降级 LLM（ARCH §4.3）
  - LLM 路径：`renderPrompt` → `RETRIEVING→PROMPT_RENDERED→LLM_PENDING` → provider 单次（5s 超时、abortSignal、freshnessDeadline）→ 校验 → `GENERATED→DISPLAY_READY`
  - 四值二次比对（session/trace/window/deadline）：`attemptFreshness`/`commentCancelled` 返回精确 reason，失败 `closeChain` 释放互斥锁
  - 展示：`DISPLAYING` + displaySink.show → `DISPLAYED`（OVERLAY_RESULT）；`finishDisplay`（M5-08 计时器目标）→ `HIDDEN` + 清窗 + windowVersion++
- `src/main/suggestion/SuggestionWindow.ts`：滚动窗口（windowMaxAgeMs/candidateMaxCount），`onEvict` 回调确保被淘汰候选审计链闭合
- `src/main/suggestion/types.ts`：ProcessingComment/PendingCandidate/SuggestionAttempt/SuggestionDisplaySink/SuggestionOrchestratorDeps
- `src/main/service/ServiceController.ts`：新增可选 `onComment`（running 分发 COMMENT）；`cleanupOnStop(reason)`；`stop(reason?)`
- `src/main/service/service-gate.ts`：`createLiveSessionWriter` 返回 sessionId
- `src/main/service/create-controller.ts`：装配编排器（stub display sink、provider factory、onAuditFailure→`controller.stop('AUDIT_UNAVAILABLE')`、cleanupOnStop 接 abortAll+endSession）
- `src/main/validation/types.ts`：`CancelTraceReason` 增加 `AUDIT_FAILURE`

### 审计状态机（严格落在 TRACE_TRANSITIONS_V1 + migration CHECK）
- 每次 transition 的 from→to 均在允许集内；reason code 落在 24 个迁移 reason；快照 role/contentType 落 CHECK
- M5-07 写：RAW_WS_EVENT/NORMALIZED_COMMENT/FILTER_DECISION/PERSONA_ROUTE/PERSONA_VERSION_SNAPSHOT/GOLDEN_QUERY_RESULT/PRE_QUERY_RESULT/RERANK_DECISION/DIRECT_PAYLOAD/DIRECT_DECISION/OUTPUT_VALIDATION/OUTPUT_SAFETY_DECISION/OVERLAY_RESULT/FINAL_REASON
- M5-09 补：RENDERED_PROMPT/LLM_REQUEST_META/LLM_RAW_RESPONSE/LLM_PARSED_OUTPUT（M5-07 仅暂存 attempt.providerAuditRecord）
- `traceState` 跟踪每条 trace 当前状态；`closeChain` 从真实末态合成到终态（DISCARDED/FAILED/HIDDEN），杜绝非法边与悬空链

### 关键决策与三轮自检修正
- **CRITICAL-1**：`endSession` 不清 `traceState`（改由下次 startSession 清），`abortAll` 同步关闭 in-flight 链，`clearAttempt` 对 STOPPED lifecycle 防御——避免停止时迟到续体写坏审计链
- **MAJOR-A**：`maybeStartAttempt` 顶部 `if (abortRequested) return`——停止期间不凭空启动新 attempt
- **CR-1**：检索失败从 `RETRIEVING→DISCARDED`（先 `ROUTED→RETRIEVING`），检索证据挂在离开 RETRIEVING 的 transition，无自环
- **CR-2**：`PROMPT_RENDERED→LLM_PENDING` 提前，配置/凭证缺失从 `LLM_PENDING→FAILED`
- **CR-5/m-1**：activity 为 DAG，新增 `enterRetrieving/enterGenerating/enterDisplaying` 辅助方法 hop `LISTENING→RETRIEVING→GENERATING/DISPLAYING`；生成期新弹幕只入窗不扰动全局 activity
- **MAJOR-1**：窗口 age/cap/clear 淘汰均 `onEvict` 闭合审计链
- **MAJOR-2**：pre-attempt 取消分支 `restoreListening()`
- **MJ-4**：所有终态（DISCARDED/FAILED/HIDDEN/FILTERED）附加 FINAL_REASON 快照
- **MINOR-1**：`handlePipelineError` 仅当失败属于当前 attempt 时才 clearAttempt
- 审计失败停服：`tryAudit` 捕获 AuditUnavailableError → abortAll + onAuditFailure（create-controller 接 stop），绝不 log-and-continue

### 不包含范围
- 全链路时钟/deadline 精化（M5-08：perf.now、精确 deadline 公式 min(t0+3000, selectedAt+2500, windowOpenedAt+windowMaxAgeMs)、展示时长计时器、晚到丢弃）——M5-07 仅做基础 `t0+3000` deadline 与基础 abort
- RENDERED_PROMPT/LLM_* 全量审计快照（M5-09）
