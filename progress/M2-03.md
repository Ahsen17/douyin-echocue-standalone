## 实现说明

### 运行方法
```ts
import { SafetyPolicyStore } from './src/main/safety/index.js';
const store = new SafetyPolicyStore({ dbPath, migrations, keyManager, keyVersion, settingsStore });

const meta = store.createDraft({ policyText, keywords });   // valid→DRAFT；歧义/非法 regex→INVALID
store.publishDraft(meta.safetyPolicyVersion);               // 仅 DRAFT；INVALID 阻止发布
await store.activatePublishedVersion(meta.safetyPolicyVersion); // 仅 PUBLISHED，写 settings
await store.getActivePublishedVersion();                    // 生效版本或 null（fail closed）
const content = store.readPolicy(meta.safetyPolicyVersion); // main 进程解密全文
store.listVersions();
store.getVersionMeta(meta.safetyPolicyVersion);
store.close();
```

## 完成标准验收

- [x] 编译器纯函数零 I/O：条款切分（；;。！？!?）、否定词（不要/禁止/请勿/别/勿/不能/不得）+ 可选动作词（讨论/提及/提到/回应/涉及/回答/谈/聊/出现）+ 明确话题；复合话题按「和/与/、」拆分各生成一条 TOPIC_PHRASE
- [x] 确定性分类法：住址/手机号/电话/姓名/家庭/地址→PII；价格/多少钱/最低价/优惠/交易/下单→TRANSACTION_PRICE；竞品/别家/友商/其他平台→COMPETITOR；政治/选举/领导人→POLITICS；医疗/用药/投资/理财→MEDICAL_FINANCIAL_ADVICE；默认 TEAM_FORBIDDEN
- [x] 歧义→INVALID：无否定词条款、话题含模糊词（不合适/敏感/大家/酌情/之类/等等）、无实义话题（含纯分隔符话题）、空 regex 模式、非法 regex、未知 compilerVersion；errors 记录条款位置
- [x] 关键词：普通词→KEYWORD 规则；`regex:` 前缀→`new RegExp()` 合法→REGEX 规则；空策略（无条款无关键词）→valid 0 规则
- [x] 夹具对齐：explicit-topics-valid 产出 PII + TRANSACTION_PRICE；ambiguous-natural-language-invalid / invalid-regex → E_SAFETY_POLICY_INVALID
- [x] 持久化：createDraft 跑编译器 → valid 落 DRAFT + compiled_rules_envelope；invalid 落 INVALID + validation_error_envelope（4 列均 AES-GCM，AAD 绑定版本 id）
- [x] publishDraft：仅 DRAFT 可发布（INVALID → E_SAFETY_POLICY_INVALID 类型化错误）；单事务置 PUBLISHED + published_at + 旧 PUBLISHED → SUPERSEDED（含故障注入回滚测试证明无中间态）
- [x] 激活：activatePublishedVersion 仅 PUBLISHED（UUIDv7 正则校验），经 SettingsStore 写 settings.activeSafetyPolicyVersion；getActivePublishedVersion 无指针/指针失效/非 PUBLISHED → null（fail closed，不抛错）
- [x] 错误契约：E_SAFETY_POLICY_NOT_FOUND / E_SAFETY_POLICY_INVALID / E_SAFETY_POLICY_IMMUTABLE / E_SAFETY_POLICY_INVALID_PARAMS / E_SAFETY_POLICY_DECRYPTION_FAILED；runTransaction 白名单不吞码
- [x] **隐私红线**：metadata 路径（listVersions/getVersionMeta）只 SELECT 元数据列、不读任何 envelope 列；输出不含策略明文/关键词/规则/envelope 列名

## 关键不变量

- 编译器确定性：同 (policyText, keywords) 必然同输出；无法解释的输入一律 INVALID，绝不静默产出空规则集
- 发布门控：INVALID（歧义/非法 regex）永久阻断发布；只有编译成功的 DRAFT 可 PUBLISHED
- 单事务原子性：publishDraft 两步 UPDATE 同事务，任何失败整体 ROLLBACK
- AAD 与版本 id + 列绑定：4 个 envelope 列只能在对应版本 id + 列名下解密（防串换）
- fail closed：无生效 PUBLISHED 版本时 getActivePublishedVersion 返回 null，运行时绝不无规则执行
- metadata 路径绝不触碰加密列
