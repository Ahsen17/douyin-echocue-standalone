## 完成标准验收

- [x] 精确匹配：displayName + 全部 enabled alias（含 TYPO_VARIANT），每成员取最长命中；唯一→exact
- [x] 歧义（多人精确命中）→ principal_fallback，candidates 保留全部命中（可审计）
- [x] 受控模糊：滑窗（len-1/len/len+1）+ Levenshtein 相似度，`>=0.8` 且唯一 → fuzzy_unique；低置信（<0.8）→ principal_fallback
- [x] 未点名 / 空 / 纯空白 → principal_fallback；无主出镜 / 空团队 → `PersonaRouterUnavailableError`（E_PERSONA_ROUTE_UNAVAILABLE）
- [x] PersonaRouter：加载 active 已发布版本 + 解密 personaMarkdown；成员无已发布版本 → 回退主出镜（decision 变 principal_fallback、candidates 保留）；主出镜无版本 → fail closed 抛错
- [x] 可审计：candidates 记录 matchedAlias + score（精确 1，模糊 [0,1]）
- [x] 契约：T-PER-001 fixture 六类验收（精确昵称/已配置变体/未点名/歧义/低可信错字/长别名高置信模糊唯一）逐条通过
- [x] 边界：displayName==alias 去重、禁用 alias 不参与、空 displayName 防御、多模糊候选歧义回退
- [x] 隐私：错误消息仅含 personaId 元数据；测试用合成文本

## 关键不变量

- 成员路由由确定性词表（名称/昵称/别名）决定，不得由 LLM/Qdrant 决定（ARCH §4.2）
- 路由输入是 M2-04 `normalizeComment` 产物（Unicode/空白/大小写已归一）
- 歧义 / 低置信 / 未点名一律保守回退主出镜，绝不猜测或随机切换
- 模糊匹配仅接受高阈值（≥0.8）且唯一；`FUZZY_MATCH_THRESHOLD` 与 fixture 契约一致
- 无主出镜或主出镜无已发布版本 → fail closed（抛错），不得静默路由到空人设
