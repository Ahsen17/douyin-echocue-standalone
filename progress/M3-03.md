const pipeline = createBm25TextPipeline();

### 已知限制
- 32-bit hash 碰撞理论可发生：单文档碰撞保留诊断（`collisions`），同 id 权重求和，不悄然换算法；POC 阶段评估碰撞对检索的影响。
- `avgDocLenBaseline` 前置条件 >0 由 `Bm25ZhJiebaProfileV1Schema` 保证（空语料 `computeAvgDocLenBaseline([])` 返回 0，调用方不得用于建 profile）。

## 自检
隔离 SubAgent 严格自检结论：**PASS**（无 P0/P1；跨语言 hash 22/22 独立复核一致）。采纳的 P2 修正：

2. `normalizationVersion` 改为 `z.literal(BM25_NORMALIZATION_VERSION_V1)` 冻结（常量移入 contracts 单一真源）；
3. `docTermWeight` 补充 avgDocLenBaseline>0 前置条件注释；
4. 修正 profile 注释引用歧义（DATA §7.2 指 09-design）。
