## 实现说明

### 运行方法
```ts
import { bootstrapPreSet } from './src/main/retrieval/index.js';
import { QdrantClient } from '@qdrant/js-client-rest';

const client = new QdrantClient({ host: '127.0.0.1', port: manager.httpPort });
const profile = await bootstrapPreSet(client, { content: jsonlBuffer });
// 成功后 alias 'pre_set'/'golden_set' 原子指向新临时 collection
```

### 设计要点
- 严格 §4.5 顺序：离线 import（M3-04）→ 一次分词 staging（避免重复分词）→ 冻结 profile → 临时双库 → upsert → 点数校验 → **smoke query 门禁** → 原子 alias 切换（单次 updateCollectionAliases，首次 bootstrap 无 delete）。
- 失败删除临时 collection、旧 active 保留（回滚窗口）；可重入（二次 bootstrap 原子替换，旧 collection 保留）。
- `computeProfileFromStaging` 用 `Bm25ZhJiebaProfileV1Schema.safeParse` 校验（拒绝全零 token 包 avg=0）。
- collection metadata 含 profile_id/qdrant_version/tokenizer/normalization 版本/k1/b/avg_doc_len_baseline/calibration。
- 写入不含 IDF（`modifier:'idf'` 在 createCollection 配置）；point_id=`uuidv5('echocue:pre_set:'+caseId)` 跨 profile 稳定。
