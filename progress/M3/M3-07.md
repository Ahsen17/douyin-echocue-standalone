## 实现说明

### 运行方法
```ts
import { SuggestionRetriever, evaluateRetrieval } from './src/main/retrieval/index.js';

const raw = await new SuggestionRetriever(client).search({ queryText, personaId, personaVersion, topK });
const result = evaluateRetrieval(raw, { topK: 10 }); // 可用 artifact 覆盖默认校准参数
// result = { calibrationVersion, goldenHits, preHits, mergedTopK, semanticDecision }
```

### 设计要点
- **校准**：`conf = 1/(1+exp(-(raw-center)/scale))`，每 collection 独立 center/scale；确定性、单调、天然 (0,1)。默认 artifact `DEFAULT_CALIBRATION_ARTIFACT_V1`（artifactId='pending-calibration' 对齐 profile，version='v1.0' 对齐 settings）为 POC 初始占位，M3-09 用甲方样本调参固化。
- **跨库 rerank**：两路校准后合并，按 confidence 降序取 topK，重排统一名次；排序键含 pointId tie-break 保证确定性。每命中保留 `collection` 来源。
- **语义初筛（§4.3）**：`filter_risk`/`low_value` 命中 max confidence ≥ `semanticDiscardConfidence` 且无更高置信度正向互动命中才 `DISCARD`（reason='LOW_VALUE'）；相等灰区、未知 semantic_type、置信不足 → `CANDIDATE`。正向类型常量 `POSITIVE_SEMANTIC_TYPES`。
- **契约**：`RetrievalHit` 带 `retrievalConfidence`；`RetrievalResult` 带 `traceId/calibrationVersion/goldenHits/preHits/mergedTopK/directPushEligible/directPointId?`（directPush 字段由 M3-08 落地）。
