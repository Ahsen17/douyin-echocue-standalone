## 实现说明

### 运行方法
```ts
import { SuggestionRetriever } from './src/main/retrieval/index.js';

const retriever = new SuggestionRetriever(client); // QdrantClient
const result = await retriever.search({
  queryText: '今天状态真好',
  personaId: 'p-1', personaVersion: 'v-1', // golden 的当前人设版本
  topK: 10,
});
// result = { preHits: RetrievalRawHit[], goldenHits: RetrievalRawHit[] }
```

### 设计要点
- 查询路径：`queryTokens` 去重 token → `{ index, value: 1 }`（不计算 tf/IDF）→ named sparse vector `bm25_zh_jieba_v1` → 双路 `Promise.all` 并行。
- filter：pre_set `enabled=true AND is_bad_case=false`（§4.1）；golden 加 `persona_id`/`persona_version`（§4.2，半对时抛错拒绝静默丢弃）。
- `normalizeHits` 返回 raw hits（pointId/caseId/collection/rawScore/rank/payload），来源区分；空查询词短路返回空。
- **范围修订**：M3-06 只返回两路 raw hits（本地类型 `RetrievalSearchResult`）；`RetrievalHitV1Schema`/`RetrievalResultV1Schema`（含 calibration confidence/mergedTopK/directPush）**延至 M3-07** 随校准实现加入，避免填充误导性占位。这是对计划的显式修订。
