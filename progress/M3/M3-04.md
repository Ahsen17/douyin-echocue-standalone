## 实现说明

### 运行方法
```ts
import { importPreSet } from './src/main/retrieval/index.js';

const result = importPreSet({ content: jsonlBuffer }); // 或 { content: string }
// 成功: { ok:true, entries: PreSetEntryV1[] }
// 失败: { ok:false, errors: [{ line, id?, path?, errorCode }] }（不含原文，无部分 entries）
```

校验链：UTF-8 无 BOM → 大小上限（默认 20 MiB）→ `TextDecoder('utf-8',{fatal:true})` 非法字节 → 行数上限（默认 100,000）→ 空包拒绝 → 逐行 JSON 对象 → ajv Schema（Draft 2020-12，additionalProperties=false）→ 重复 id → 安全（`detectBuiltinRisk` 对 text/description/reference_reply）。任一失败整体拒绝。

### 已知限制
- 空包（0 行）拒绝为 `PRE_SET_EMPTY`（保护 §7.3 avg_doc_len_baseline 计算不落入 0/undefined）。
- 安全校验只查内置 detector（M2-04），不含团队自然语言策略；文本必须已脱敏由甲方保证。
- `enabled` 跟随 Schema 的 `type:boolean`（正文为"初始建议均为 true"），导入器不强制 true。
