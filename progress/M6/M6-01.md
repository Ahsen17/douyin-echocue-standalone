## 实现说明

### 共享基建（批次共用，本任务首建）
- `src/shared/ipc-channels.ts`：IPC channel 常量唯一来源（window/service/provider/config/persona/safety/diagnostics 全量预声明），三端相对 import；现有 wire 的硬编码字符串换用常量（字符串值不变，行为等价）
- `src/main/ipc/guarded-handler.ts`：`createGuardedHandler<S, T>(isTrustedSender, handler)`，未可信 sender 同步 throw `'rejected: untrusted sender'`；`service.start/stop`、`provider.credential.set/clear/test` 全部改用（T-IPC 基础）
- `src/preload/main-preload.ts` 导出 `EchocueApi` 类型；`src/renderer/main/echocue.d.ts` 改为 `import type` 推导（纯类型，无 electron 运行时；renderer 产物 electron 引用计数 0 已验证）
- tsconfig.json / tsconfig.node.json include 加 `src/shared`
- `state-broadcast` 保留显式守卫（subscribe 需 event.sender 注册订阅，不适合 createGuardedHandler）

### 包含范围
- `src/renderer/main/nav.ts`：`NAV_ITEMS` 恰好七入口（运行/直播间/团队与人设/安全与禁忌/浮窗偏好/诊断/审计追溯）+ `isNavItem`；overlay 独立窗口不入 nav
- `src/renderer/main/App.tsx`：七入口侧边栏导航（active 高亮 + aria-current="page"）+ 保留 M1-06 titlebar（三按钮/aria-label/最大化切换/键盘激活）；`pages: Record<PageName, ComponentType>` 类型强制全键覆盖
- `src/renderer/main/components/StateViews.tsx`：`EmptyState/LoadingState/ErrorState/PrivacyNotice/PagePlaceholder`；ErrorState 对 message 做控制字符剥离 + 长度截断，code 以 badge 呈现（不泄漏 provider/Qdrant/WS 内部）
- `src/renderer/main/styles.css`：从 `prototype/src/styles.css` 迁移
- 七个页面占位（RunPage/RoomAiPage/PersonaPage/SafetyPage/PreferencesPage/DiagnosticsPage/AuditPage），后续任务替换
- 测试：`tests/unit/ipc/guarded-handler.test.ts`（可信/不可信/透传/无 payload）、`tests/unit/renderer/nav.test.ts`（七入口/overlay 排除/isNavItem）

### 不包含范围
- config/persona/safety/diagnostics IPC 通道已预声明未接线（M6-02~05）
- overlay 独立窗口与 `overlay.*` IPC（M6-07）
- 审计 `audit.*` IPC（M6-09/10）
- T-IPC 全量越权矩阵与 frame URL 校验（M6-11）
