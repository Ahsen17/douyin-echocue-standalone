## 实现说明

### 包含范围
- 契约（`src/contracts/src/schemas.ts` + docs 逐字节同步）：`DiagnosticSummaryV1` 新增可选 `storageAvailableBytes`（非负整数，UI §8.1 容量展示；M7-07 容量演练前的展示字段）
- `src/main/telemetry/DiagnosticsSource.ts`：构造注入 `readStorage?: () => StorageCapacity | null`；`getSummary()` 返回可用字节，低于 `max(1 GiB, 卷容量 10%)`（RUNBOOK §4.1）时置 `lastDomainError='E_STORAGE_LOW'`；读失败或缺依赖时省略容量字段（不误报）
- `src/main/service/create-controller.ts`：用 `fs.statfsSync(dataDir)` 提供 `readStorage`（available = bavail × bsize，total = blocks × bsize；异常返回 null）
- `src/renderer/main/pages/DiagnosticsPage.tsx`（替换占位）：metrics 网格（运行状态/最近接收/最近建议结果/最近端到端耗时/审计存储可用）+ `E_STORAGE_LOW` 预警卡 + 「复制脱敏诊断摘要」+ 刷新；空/加载/错误状态（UI §9 诊断行）
- `src/renderer/main/diagnostics/diagnostics-logic.ts`（新增，纯函数）：`formatBytes`（GiB/MiB/B）、`localizeSuggestionResult`（displayed→已展示后隐藏 等）、`localizeDomainError`（E_* 处置提示）、`buildCopyableSummary`（只含脱敏字段）
- 测试：
  - `tests/contract/T-DIAG-001-diagnostic-privacy.test.ts`：5 个 `it.todo` 全部填实 + 2 个新增（无正文/人设/Key/trace_id、仅语义类别、容量阈值触发 E_STORAGE_LOW、读失败省略）
  - `tests/unit/renderer/diagnostics-logic.test.ts`（9 例）：容量格式化、结果/错误本地化、脱敏摘要不含敏感字段
  - `tests/contract/test/schemas.test.ts` +2：storageAvailableBytes 正常/负数拒

### 产品取舍（已确认）
- 「预计可用时长」标注缺增长基线（依赖 POC 每千条增长量，M3-09 阻塞），本批只展示容量 + E_STORAGE_LOW 预警，不做估算公式
