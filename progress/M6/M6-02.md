## 状态
已完成（2026-08-22）

## 实现说明

### 包含范围
- 契约（`src/contracts/src/schemas.ts` + docs 同步逐字节）：`ConfigViewV1Schema`（脱敏配置视图，不含 internalRetrieval、Key 仅 `apiKeyConfigured`）、`ProviderConfigInputV1Schema`（adapter 仅 DEEPSEEK/OPENAI_COMPATIBLE，ANTHROPIC 无 adapter 不出项）、`ConfigUpdateRequestV1Schema`、`PersonaSummaryV1Schema`、`DiagnosticSummaryV1Schema`
- 只读 IPC（`createGuardedHandler` 全部门禁）：
  - `config.get` / `config.update`（`src/main/config/config-control-handlers.ts`，update 本批仅 roomReference，provider 写显式拒绝；`ConfigCorruptError`→中文可读错误）
  - `persona.list`（`src/main/persona/persona-control-handlers.ts`，本批只读）
  - `diagnostics.getSummary`（`src/main/telemetry/diagnostics-control-handlers.ts`，匿名摘要）
- `create-controller.ts`：`CreatedServiceController` 暴露 `settings/persona/safety/diagnostics`；orchestrator deps 接线 `onCommentReceived`（handleComment 入口）/`onSuggestionResult`（filter/fail/discard/display 成功分支，带 e2e）到 `DiagnosticsSource`；`index.ts` 用 `services.diagnostics.updateLifecycle` 更新生命周期
- Renderer：
  - `run/run-state.ts`：`deriveRunState` 9 态映射（含 audit-down 两路径：`stopReason='AUDIT_UNAVAILABLE'` 与 `SOURCE_ERROR`+`recoverableError.code='E_AUDIT_UNAVAILABLE'`）+ `computeConfigCompleteness`（直播间/AI/主要出镜人设）
  - `run/recent-activity.ts`：`formatRecentActivity`（结果中文标签 + 时间）
  - `hooks/useServiceState.ts`、`hooks/useAsyncAction.ts`
  - `pages/RunPage.tsx`：状态卡（生命周期+停止/启动/重试/查看诊断，按 `deriveRunState` 分发）+ 当前直播间/团队/主要出镜摘要 + 最近活动卡（含浮窗偏好入口）+ 完成配置清单（缺失项直达配置页）；AUDIT_UNAVAILABLE 禁启动但「查看诊断」可点
  - `App.tsx` 传 `onNavigate`；`nav.ts` 加 `PageProps`
- 测试：契约 +14、config/diagnostics/persona handler（含隐私断言）、run-state（9 态 + completeness）、recent-activity、orchestrator 钩子（display e2e / filtered）

### SubAgent 自检修复项
- P1：audit-down 态「查看诊断」主按钮被 `startDisabled` 误禁用 → `disabled` 仅对 start/retry 生效
- P2-1：`reload.error`（config/persona/diagnostics 加载失败）纳入错误展示
- P2-2：`DiagnosticsSource.recordSuggestion` 非 displayed 结果清空 `lastE2eLatencyMs`（避免旧值残留）
- P2-3：补 orchestrator 钩子单测（display e2e=1000 / filtered）
