## 实现说明

### 包含范围
- 契约（`src/contracts/src/schemas.ts` + docs 逐字节同步）：`OverlayDisplayPayloadV1`（comment.nickname 可选 min1 max64 / comment.text min1 max2000 / suggestion）、`OverlayDisplayRequestV1`（requestId + payload）、`OverlayAckRequestV1`（requestId）；`trace_id` 不进 overlay renderer，requestId nonce 匹配 ack
- `SuggestionDisplaySink.show()` 签名改为 `(payload: OverlayDisplayPayloadV1, meta)`；orchestrator display() 用 `attempt.comment.userNickname || undefined` + `normalizedText` 组装 payload
- `src/main/windows/OverlayWindow.ts`（重写）：showInactive 不抢焦点、首帧 ack（pendingAcks Map + ackTimeoutMs 默认 1500ms，主进程收 ack 打 `performance.now()`）、点击穿透 `setIgnoreMouseEvents(clickThrough, {forward:true})`、跨屏回退（`screen.getAllDisplays` 无交集 → 主屏右下 16px clamp）、`lastAppliedSize` 手动 resize 优先、prefs live-apply、waitReady 2s 超时兜底、destroy 以 `OVERLAY_DESTROYED` 收尾 in-flight show
- `src/main/overlay/{overlay-display-sink,overlay-control-ipc,index}.ts`：sink 丢弃 meta（trace_id 留主进程）；`overlay.ack` 通道经 `createGuardedHandler(isOverlayTrustedSender)` 校验 sender 为 overlay window 自身
- `src/main/index.ts`：eager OverlayWindow（懒读 settings）、`displaySink` 注入 createServiceController、cleanupOnStop 隐藏、doQuit destroy、wireConfigControl 传 overlayWindow（偏好写后 live-apply）
- overlay-preload 最小权限：仅 `onDisplay/onHide/onPreference/ack`，无 config/persona/audit/service
- `src/renderer/overlay/App.tsx` + `echocue.ts`：渲染 @昵称（缺失隐藏）+ 正文 + 短回复 + 2~3 提词，主题/字号随偏好，双 rAF 后 ack，不显示 trace_id/分数/来源
- 测试：契约 11 例、`tests/e2e/T-OVR-001`（5 todo 替换为真实窗口行为测试，vi.mock electron：显示+ack / 到期隐藏 / 点击穿透 / 单展示不自我二次渲染 / 跨屏回退 + 补 ack 超时 + destroy 收尾）、`tests/unit/overlay/overlay-display-sink`（4 例含隐私断言）、orchestrator payload 组装断言、集成测试 shown 断言改 `.suggestion`

### SubAgent 批次自检修复项（M6-06+07 统一一轮）
- P1-1（中，M6-06 引入）：display() 在 DISPLAYED 后 `await getDisplayDurationMs` 引入挂起点——abort 期间续体会给已清空 attempt 挂定时器，误伤下一次展示 → getter await 后补 `if (this.attempt !== attempt) return`（abortAll 已 hide，无孤儿）；补回归测试（hide 计数 + attempt 置空）
- P2-1：`getDisplayDurationMs` 未防护 settings 损坏 → 兜底默认 10s
- P2-2：updateOverlay 先持久化后 live-apply，apply 失败误报保存失败 → apply 降级 best-effort（try/catch 吞掉），持久化成功即成功；补回归测试
- P2-3：showSuggestion await 后陈旧 win 引用 → 重读 `this.window` 判空
- P2-5：跨屏回退在窗口大于主屏时产生负 x → clamp 到 workArea 内
- P2-6：偏好页文案「应用于下一次展示」不准确（视觉项即时应用）→ 改为「视觉项即时应用，展示时长用于下一次展示」
- P2-7：T-OVR-001 补 ack 超时 + destroy 清理用例；destroy 改为以 `OVERLAY_DESTROYED` resolve pending（防 quit 挂起）
- 既有 closeChain 对 DISPLAYED 取消路径本就写 `HIDDEN:DISPLAY_DURATION_ELAPSED`（合法终态），非定时器证据——回归测试改用 hide 计数判定

### 产品取舍（已确认）
- 展示内容只含 @昵称 + 正文 + 短回复 + 提词；位置「上次位置」为窗口进程内保留（不落 settings 契约），跨屏失效回退主屏右下角
- requestId 由 sink 用 uuidv7 生成，overlay renderer 全程不见 trace_id；meta（sessionId/traceId/windowVersion）仅留在 orchestrator 审计
- 偏好 width/height 为默认尺寸，`lastAppliedSize` 让手动 resize 优先，仅偏好本身变更时强制

### 不包含范围
- 诊断页完整 UI（M6-08）、审计列表/workflow（M6-09）、打标（M6-10）、IPC 全量越权矩阵（M6-11）
