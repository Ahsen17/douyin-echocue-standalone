# M6-04 团队与人设页

## 状态
已完成（2026-08-22）

## 实现说明

### 包含范围
- 契约（`src/contracts/src/schemas.ts` + docs 同步逐字节）：`AliasKindV1/AliasInputV1/AliasRowV1/PersonaVersionMetaV1/VersionComparisonV1/PersonaDetailV1`（含 `editableContent` 供授权编辑页预载人设内容）、`PersonaCreateRequestV1/PersonaSaveDraftRequestV1`（content 或 fromVersion 至少其一）/`PersonaPublishRequestV1/PersonaUpdateAliasesRequestV1` 等
- `src/main/persona/persona-control-handlers.ts`：补全 `get`（详情 + editableContent，取**最新**草稿否则 active 版本）、`create`（uuidv7 + 首成员自动 principal）、`delete`（主出镜拒绝）、`setPrincipal`、`saveDraft`（content 缺省 + fromVersion → `readVersionContent` 拷贝，即回滚生成新草稿）、`publish`（publishDraft → getVersionMeta）、`listVersions`、`compare`、`updateAliases`（diff listAliases → addAlias/updateAlias/deleteAlias 替换语义）；领域错误全部翻译为中文用户可读消息
- `persona-control-ipc.ts` 注册全部 `persona.*`（经 `createGuardedHandler`）；preload 暴露 persona 全部方法
- `src/renderer/main/persona/persona-logic.ts`：`parseAliases`（中文/英文逗号顿号拆分去重）/`aliasText`/`formatVersion`
- `src/renderer/main/pages/PersonaPage.tsx`：左成员列表（●主出镜 + 已发布摘要）右编辑区（别名 + 人设 textarea + 预览 + 保存草稿 + 发布（确认框 + 运行中提示下次启动生效）+ 版本历史（查看/比较/回滚）+ 空态/错误/重试）
- 测试：真实 PersonaStore(sqlite) 集成 handler（create 首成员 principal / saveDraft+publish / get editableContent 最新草稿 / fromVersion 回滚 / setPrincipal 唯一 / 删除主出镜拒绝 / updateAliases 替换 / compare / 隐私响应无内容）+ persona-logic 纯函数

### SubAgent 自检修复项
- P1-1：编辑/发布读取**最旧**草稿而非最新（listVersions ASC + createDraft 追加行）→ handler 与页面均取 `[...versions].reverse().find(DRAFT)`，补回归测试（两次 saveDraft 断言返回第二次内容）
- P1-2：成员切换/删除后编辑缓冲（draftText/aliasInput）残留上一成员内容可能串写 → 删除时清空缓冲 + `canEditSelected`（detail.personaId===selectedId）守卫 saveDraft/saveAliases/rollback
- P2-1：初始加载失败静默卡 LoadingState → members null 且有 reloadList.error 时渲染 ErrorState + 重试；error 并入 reloadList/loadDetail.error
- P2-2：主出镜删除按钮禁用（title 提示需先指定另一名主出镜）
- P2-4：隐私测试扩展到 publish/compare/setPrincipal/updateAliases 响应
