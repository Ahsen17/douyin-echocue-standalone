## 实现说明

### 包含范围
- 契约（`src/contracts/src/schemas.ts` + docs 逐字节同步）：`AuditSearchRequestV1`（from/to 时间范围 + **finalState 结果筛选**（新增，UI §8.2） + labelStatus + page/pageSize 默认 1/20，pageSize 1–100）、`AuditGetWorkflowRequestV1`（UUID v7）、`AuditTraceSummaryV1`（traceId/receivedAt/finalState 可空/labelStatus/hasSuggestion/commentText）、`AuditSearchResponseV1`（items+total+page+pageSize）、`AuditWorkflowV1`（Buffer plaintext → utf-8 string，transitions 按 sequenceNo + snapshots role/contentType/plaintext）
- CONTRACT §7 文档修复：`audit.search` 行补「结果（final_state）」筛选（UI §8.2 要求，原 schema/表缺少）
- `AuditStoreWorker.searchTraces(params)`：按 from/to/finalState/labelStatus 过滤 + `LIMIT/OFFSET` 分页 + `COUNT(*)` 总数 + `received_at DESC`；每行 `commentText` 从首个 `NORMALIZED_COMMENT` 快照按需解密（失败返回空串，不污染整页）、`hasSuggestion` 判定（存在 DISPLAYED/HIDDEN 迁移）
- `AuditStoreWorker.getTraceWorkflowV1(traceId)`：复用 getTraceWorkflow，Buffer→utf-8 可序列化投影
- `src/main/audit/{audit-control-handlers,audit-control-ipc,index}.ts`（新增）：search/getWorkflow 经 `createGuardedHandler(isTrustedSender)` 仅主窗口可调；校验失败 message「审计查询参数不合法」「traceId 必须是合法的 UUID v7」「未找到该条审计」
- `create-controller.ts`：`CreatedServiceController` 暴露 `audit`；`src/main/index.ts` wire `wireAuditControl`
- preload `audit.search/getWorkflow`（submitLabel 留 M6-10）
- `src/renderer/main/pages/AuditPage.tsx`（替换占位）+ `src/renderer/main/audit/audit-logic.ts`：本机访问授权提示 → 确认后才查询；筛选栏（处理结果 finalState / 打标状态）；分页列表（每页 50，received_at DESC）；记录详情双 tab：工作流上下文时间线（transitions + snapshots 按需展开原文）+ 查看/编辑打标入口（M6-10 LabelForm 挂载点，当前只读状态）
- 测试：契约 15 例新增（search 完整筛选/finalState/extra/non-datetime、TraceSummary 正常/null/缺字段/extra、SearchResponse、Workflow Buffer 拒/非法 role、SubmitLabelResponse）、`tests/unit/audit/audit-search-handlers`（6 例：search 透传/非法拒/strict 拒、getWorkflow 命中/非 v7 拒/未找到）、`tests/unit/renderer/audit-logic`（9 例：finalState/labelStatus 本地化、pageCount、timeline、defaultRevisionCount、shortTime）、T-AUD-001 集成 +3（search 过滤/分页/commentText 解密/hasSuggestion、getWorkflowV1 序列化、未知 trace null）

### 产品取舍（已确认）
- 列表 commentText 是授权审计页内按需解密（CONTRACT §7 白名单），overlay 无 audit.*，绝不越权
- workflow 快照原文以 `<details>` 按需展开，避免默认全量渲染大 payload
- 既有 M6-07 预置 schema（`expectedRevisionNo` 乐观锁、`score` 派生打标状态）为权威形态，本批采纳并在其上扩展而非另起一套

### 不包含范围
- 打标提交与 LabelForm（M6-10）、IPC 全量越权矩阵（M6-11）
