# M0-02 任务总结

## Summary

建立了 `@echocue/contracts` 共享契约包，包含完整 Zod schemas、状态枚举和状态转换规则。Main/Preload/Renderer 三个进程均可通过 `@echocue/contracts` 导入，禁止字符串枚举复制。

## 产出文件

| 文件 | 说明 |
| --- | --- |
| `src/contracts/package.json` | `@echocue/contracts` 包配置，name/version/exports |
| `src/contracts/src/schemas.ts` | 完整 Zod schemas（来自 contracts-v1.ts），状态转换常量 |
| `src/contracts/src/index.ts` | 统一导出入口 |
| `src/contracts/test/schemas.test.ts` | 40 个契约测试：正常/边界/失败路径，Node.js 直接可运行 |
| `package.json` | 新增 workspaces、`@echocue/contracts` 依赖、`test:contracts` 脚本 |
| `tsconfig.json` | 新增 paths 映射 `@echocue/contracts` → contracts/src |
| `tsconfig.node.json` | 同上，覆盖 main/preload 进程 |
| `src/main/index.ts` | 验证性 import，确认 Main 进程可成功引用契约包 |
