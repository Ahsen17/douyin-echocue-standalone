const newId = store.rollbackTo(personaId, targetVersionId);            // 同 persona 非 DRAFT 目标

## 完成标准验收

- [x] `createDraft`：UUIDv7 新行，envelope=`FieldEncryptor.encrypt(utf8(content), buildAad('persona_version', id, 'PERSONA_TEXT'))`，`content_hmac=contentHmac(content)`，status=DRAFT；`fromVersion` 须为同 persona 既有版本（DB 父 guard 触发器兜底）
- [x] `updateDraftContent`：仅 DRAFT 可改，PUBLISHED/SUPERSEDED → `PersonaVersionImmutableError`（发布版本不可变）；重加密 AAD 仍绑定该版本 id
- [x] `publishDraft`：单事务置 PUBLISHED + published_at → 旧 active 置 SUPERSEDED → `persona.active_version` 原子切换（guard 触发器校验 PUBLISHED + 同 persona）
- [x] `rollbackTo`：同 persona 的 PUBLISHED/SUPERSEDED 目标；解密在事务外（失败零写入）；单事务新建 PUBLISHED 行（created_from_version=target）并立即切换 active；绝不改动既有行内容/hmac；相同内容必然产生新行（不去重）
- [x] `compareVersions`：仅比对 `content_hmac` 判定 `sameContent`，零解密
- [x] `readVersionContent`：解密还原；损坏/AAD 错配 envelope → `PersonaContentDecryptionError`；仅 main 进程路径
- [x] 错误契约：E_PERSONA_VERSION_NOT_FOUND / E_PERSONA_VERSION_IMMUTABLE / E_PERSONA_CONTENT_DECRYPTION_FAILED；跨 persona / DRAFT 目标 / 空 content → E_PERSONA_INVALID_PARAMS；未知 id → not-found；`runTransaction` 白名单含新错误，类型化错误不被包装吞码
- [x] **隐私红线**：metadata 路径（getVersionMeta/compareVersions/listVersions/createDraft 父校验/updateDraftContent/publishDraft 状态校验）**不读取 content_envelope 列**（`getVersionRow` 默认 metadata-only SELECT，仅 readVersionContent/rollbackTo 传 includeEnvelope=true）；所有 metadata 输出不含正文与 envelope 字节
- [x] uuidv7：RFC 9562（48-bit ms 时间戳 + ver=7 + variant 10xx），位级验证匹配契约正则 `/^[0-9a-f]{8}-[0-9a-f]{4}-7[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/i`
- [x] DDL guard 触发器（persona_version_parent_guard / persona_active_version_guard_*）以 raw-SQL 负向用例直测（跨 persona 父版本 INSERT 拒绝、active_version 指向 DRAFT 拒绝）

## 关键不变量

- 发布版本不可变：PUBLISHED/SUPERSEDED 行内容与 hmac 永不改变；回滚只新增行，不改旧行
- 单事务原子性：publishDraft/rollbackTo 内任何一步失败整体 ROLLBACK，不存在「旧 active 已 SUPERSEDED 但新版本未插入」的中间态
- AAD 与版本 id 绑定：envelope 只能在对应版本 id 下解密（防行间串换）；hmac 与加密均基于同一 content 原文
- metadata 路径绝不触碰加密列：读面最小化，仅需解密的两个入口读取 content_envelope
- 相同内容可并存：content_hmac 无唯一约束，回滚/重复发布同内容产生不同 ID 的新行
