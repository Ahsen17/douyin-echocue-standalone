## 实现说明

### 运行方法
```ts
import { ServiceStateMachine } from './src/main/service/index.js';
const machine = new ServiceStateMachine();          // 初始 STOPPED/IDLE
machine.onChanged((state) => { /* service.state.changed 广播源 */ });
machine.transitionToLifecycle('GATE_CONNECTING');   // activity→GATE_CHECKING
machine.transitionToLifecycle('RUNNING');           // activity→LISTENING
machine.setActivity('RETRIEVING');
machine.transitionToLifecycle('STOPPED', { stopReason: 'ROOM_ENDED' });
```

### 设计要点
- **lifecycle 转换**：消费契约 `SERVICE_LIFECYCLE_TRANSITIONS_V1`；非法迁移（含自迁移）抛 `ServiceStateInvalidTransitionError`（复用 AuditStoreWorker validateTransition 模式）。
- **activity 约束**：按 lifecycle 白名单（STOPPED 仅 IDLE、GATE_CONNECTING 仅 GATE_CHECKING、RUNNING 仅四值）+ RUNNING 内按 ATLAS §8.1 转换表（LISTENING→RETRIEVING→GENERATING/DISPLAYING→LISTENING）；同值 set 为 no-op 不广播。
- **初值与清除**：进入各 lifecycle 重置 activity（STOPPED→IDLE、GATE_CONNECTING→GATE_CHECKING、RUNNING→LISTENING）；进入 STOPPED 携带 stopReason/recoverableError，离开 STOPPED 两项清除。
- **IPC 广播**：`service.state.subscribe`（invoke）→ `service.state.changed`（事件），对齐 CONTRACT §7；Main 校验受信 sender、立即回推快照、窗口 destroy 自动注销；Renderer 无推导路径。
- **类型**：`recoverableError` 用 `NonNullable<ServiceViewState['recoverableError']>` 契约派生；preload/renderer 类型均从 `@echocue/contracts` 导入，不复制枚举。
