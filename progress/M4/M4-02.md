## 实现说明

### 运行方法
```ts
import { DouyinLiveWsAdapter } from './src/main/douyin/index.js';

const adapter = new DouyinLiveWsAdapter({ host: '127.0.0.1', port: 1088, roomReference: 'room-abc' });
adapter.onEvent((event) => { /* LIVE_ONLINE/LIVE_OFFLINE/LIVE_ENDED/COMMENT/SOURCE_ERROR */ });
await adapter.connect();
adapter.close();
```

### 设计要点
- **契约**：`LiveSourceEventSchema` 为 `discriminatedUnion('type')` 五分支；`SourceComment` 含 `receivedMonotonicMs`（收到原始 WS frame 时 `performance.now()` 采样，统一 t0）。`SOURCE_ERROR.code` 引用 `DomainErrorV1Schema`，不复制字符串。
- **映射**：`ROOM_ONLINE→LIVE_ONLINE`（带 platformRoomId）、`ROOM_OFFLINE→LIVE_OFFLINE`、`ROOM_ENDED→LIVE_ENDED`、未知 `live_status` code→SOURCE_ERROR、`WebcastChatMessage→COMMENT`；礼物/点赞/非对象帧→null（仅匿名连接诊断，不产生 COMMENT）。
- **msgId 精度**：douyin 真实 JSON 中 `common.msgId`/`roomId` 为字符串（超过 `Number.MAX_SAFE_INTEGER`）；adapter 优先按字符串透传，缺失时生成 `local-${uuidv7()}` 临时 ID，不以正文作去重键。
- **normalizedText**：复用 M2-04 的 `normalizeComment`（regex→NFKC→case→空白），避免重复实现。
- **生命周期**：`connect()` open→resolve / 连接错误→reject（不广播）；`close()` 无条件 `ws.close()`（CONNECTING 时 abort handshake）；仅在上线后异常关闭广播一次 SOURCE_ERROR；无自动重连。
- **schema 校验**：mapped event 经 `LiveSourceEventSchema.safeParse` 通过后才广播。
