## 实现说明

### 运行方法
```ts
// 主进程装配（见 create-controller.ts）
const { controller, stateMachine, shutdown } = await createServiceController({...});
await controller.start();   // 门禁 → sidecar → WS → ROOM_ONLINE → RUNNING
await controller.stop();    // 清理 → STOPPED USER_STOP
```

### 设计要点
- **门禁链**（RUNBOOK §4.1）：配置(roomReference/provider) → 凭证 → 审计可写 → 已发布人设/安全规则 → Qdrant 健康+pre_set alias → 拉起 sidecar → 建 WS → GATE_CONNECTING/GATE_CHECKING → 仅 ROOM_ONLINE 建 session → RUNNING；任一失败回 STOPPED + recoverableError（E_CONFIG_INVALID/E_AUDIT_UNAVAILABLE/E_SAFETY_POLICY_INVALID/E_QDRANT_UNAVAILABLE/E_SIDECAR_START_FAILED/E_SOURCE_UNAVAILABLE），不拉起 sidecar/WS。
- **停止流程**（RUNBOOK §4.2）：cleanupOnStop → 关 WS → 停 sidecar → STOPPED；stopReason 映射 USER_STOP/ROOM_ENDED/ROOM_OFFLINE/SOURCE_ERROR/AUDIT_UNAVAILABLE。审计不可写（createSession 失败）→ AUDIT_UNAVAILABLE 停止。
- **并发安全**：start() 开头置 phase='gate' 关闭重入窗口 + 入口 `phase!=='idle'||lifecycle!=='STOPPED'` 双守卫；stop() 是唯一清理所有者（`stopPromise`），start() 的 abort 检查点统一 `afterAbort()` 等待 stop 完成、不重复清理；`phase='idle'` 在 enterStopped 内复位；RUNNING 转换前双重重校验（createLiveSession 前后）；stop 在 gate 阶段 resolve ABORTED 不悬挂。
- **快照**：createSession 写入 `safetyPolicyVersion`（来自 settings.activeSafetyPolicyVersion）；人设版本快照无落库位置，属 M5（M5-09 全量审计快照）接线范畴。
- **doQuit()**：托盘退出先 `controller.stop()`（关 WS + 停 sidecar）再 `shutdown()` 关闭各 store，符合 RUNBOOK §4.3 停止顺序。
