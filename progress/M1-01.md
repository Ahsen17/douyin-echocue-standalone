# M1-01 任务完成总结

## Summary

实现了 `settings.json` 配置仓库（SettingsStore），支持原子写入、Zod 校验和敏感字段保护。

## 产出文件

| 文件 | 说明 |
| --- | --- |
| `src/main/config/SettingsStore.ts` | SettingsStore 核心实现，含 ConfigCorruptError |
| `src/main/config/index.ts` | 模块导出入口 |
| `tests/integration/config/settings-store.test.ts` | 16 个集成测试，覆盖正常、边界、失败和权限路径 |
| `vitest.config.ts` | 修复 include 规则，排除 src/contracts/test/schemas.test.ts 被 vitest 误拾取 |

## 关键实现

- **原子写入**：temp 文件 → `fsync` → `rename`，崩溃只留旧或新内容，不会有中间态
- **严格 schema 校验**：使用已有 `SettingsV1Schema`（`z.strictObject`），未知字段被拒绝，无重复 schema 定义
- **ConfigCorruptError**：读取损坏/未知字段时抛出，不修改也不删除原文件
- **敏感字段隔离**：`ProviderConfigV1` 仅含 `credentialRef`（引用键），API Key 不进入 settings.json
