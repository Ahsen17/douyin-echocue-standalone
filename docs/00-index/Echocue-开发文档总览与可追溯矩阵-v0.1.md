# Echocue 开发文档总览与可追溯矩阵 v0.1

> 状态：开发基线索引  
> 用途：统一各文档的权威范围、阅读顺序与交叉引用；不替代任何原始需求或设计结论。

## 1. 使用规则

1. 需求事实以《需求澄清与 MVP 定义》和甲方后续书面确认优先；不得以工程方便为由改变。
2. 产品行为以 PRD 优先；技术实现以技术调研、架构、数据/接口契约和详细设计图册共同约束。
3. 当文档间存在冲突时，先记录问题，不得静默删改较早文档；由甲方确认或以明确的后续决策记录更新。
4. 本索引只重新组织引用关系，不删除、不简化、不重述既有关键决定。

## 4. 推荐阅读顺序

1. 产品/需求：01 → 02；
2. 技术决策：03 → 04 → 09-A；
3. 数据与接口：05 → 06 → 09-B；
4. 前端/桌面：02 → 10 → 06 IPC；
5. 生成与运行实现：11-A → 11-B；
6. 实施与验证：08 → 07。

## 5. 发布前完整性检查

- 每个 P0 验收项都能回链到至少一个需求、设计图/契约和测试证据；
- 所有 Mermaid 图以源码随文档保存，开发和评审以源码为准；
- 涉及状态、数据或接口的变更同步更新 04、06、09-A/09-B、08 和本矩阵；
- UI 行为变更同步更新 02、10、08；
- 未完成真实 `douyinLive` POC 时，07 的 release gate 仍保持未关闭。
